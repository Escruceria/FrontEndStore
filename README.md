# FrontEnd Store

FrontEnd Store es una tienda estática de camisetas para desarrolladores. El sitio incluye una página principal con catálogo, una sección de información sobre la marca y una página de detalle de producto.

## Vista general

El proyecto está construido con HTML y CSS puro. Mantiene una estructura sencilla, fácil de leer y pensada para practicar maquetación web, organización de estilos y diseño responsivo.

## Páginas

- `index.html`: catálogo principal de productos.
- `nosotros.html`: presentación de la tienda y beneficios de compra.
- `producto.html`: detalle de una camiseta y formulario de compra.

## Tecnologías utilizadas

- HTML5
- CSS3
- Normalize.css
- Google Fonts

## Estructura del proyecto

```text
FrontEndStore/
├── css/
│   ├── normalize.css
│   └── style.css
├── img/
│   ├── productos e imágenes del sitio
│   └── iconos de beneficios
├── index.html
├── nosotros.html
├── producto.html
└── README.md
```

## Cómo abrir el sitio

Abre `index.html` directamente en el navegador o ejecútalo desde un servidor local como XAMPP.
